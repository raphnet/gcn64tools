# No "AI" policy

This project does not use any "AI"[1] generated code or code written with "AI" assistance, and as a maintainer,
it is my wish to keep things that way.

Please do not submit "AI" generated code (or "co-authored" code) whatsoever, as regardless of its potential
correctness they will be rejected. [2]

I would also kindly ask that when communicating with me regarding issues, bugs, and feature request, you
use your own words. Likewise for commit and pull request messages.

Thank you!

[1] "AI" here means LLMs and Generative AI. Traditional algorithmic code analysis tools
(code completion and styling, compiler warnings, static code analysis tools) are acceptable.

[2] Should you wish to do so, this project license does not prevent you from renaming and forking
the project and changing this policy.
